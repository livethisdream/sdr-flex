# OFDM, with the message written on the grid

64 subcarriers, a 16-sample cyclic prefix, 400 µs symbols, QPSK on whichever subcarriers
are lit. 200 kS/s complex on 2.412 GHz.

**The occupancy pattern spells `SDR`.** That is the point of the fixture rather than a
flourish: in OFDM the message can be *which* cells carry anything, in time and in
frequency, and a grid recovered with the symbol boundaries even slightly wrong smears the
letters. It fails where you can see it.

Nothing about the structure is recorded anywhere the analyzer can read it. The FFT size,
the prefix length and the symbol period are recovered by correlating the signal against
itself at each plausible lag — a cyclic prefix is a copy of a symbol's own tail pasted in
front of it, so a stretch of samples identical to another stretch exactly one FFT length
later, recurring once per symbol, is a signature nothing else has.

**Nobody transmitted this.** Generated by `fixtures/make.mjs` from a fixed seed; it
regenerates byte for byte. The QPSK content comes from the same seeded generator, because
the content is not the point and a fixture whose content changes between runs is not a
fixture.
