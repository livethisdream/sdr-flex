Where the bars go

Five layouts for the same screen, built from web/style.css so the only thing that differs between them is where the chrome sits. The figures under each are measured off the rendered DOM at the chosen viewport, not typed in. Today the app spends 174 px on chrome at every width — 19 % of a 1440×900 laptop and 25 % of a 1024×700 one — across four full-width rows, two of which are about 11 % full.
